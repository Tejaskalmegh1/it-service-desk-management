# Knowledge Base: Basic Windows Troubleshooting

**Article ID:** KB-WIN-001  
**Category:** Operating System / Desktop Support  
**Audience:** L1 support practice

## Scenario: Windows computer is running slowly

### Initial questions

- When did the slowdown begin?
- Is it constant or limited to one application?
- Did the user recently install software or updates?
- Is the device showing an error or unusual noise/heat?

### Safe first-line checks

1. Confirm whether one application or the whole computer is slow.
2. Save the user's work before any restart.
3. Check available storage in Windows Settings.
4. Open Task Manager and observe CPU, memory, and disk usage.
5. Identify whether a known application is consuming unusually high resources.
6. Check whether updates or a scan are currently running.
7. Restart only after confirming the user has saved work and it is appropriate.
8. Record observations and results in the ticket.

### Escalate when

- The device repeatedly freezes or shuts down.
- Disk or hardware errors appear.
- There are signs of malware or compromise.
- The issue persists after approved basic checks.

### Ticket documentation example

**Checks:** Reviewed Task Manager, checked available storage, confirmed no update was in progress, and restarted with user approval.

**Outcome:** Performance improved temporarily; monitoring or further diagnosis may be required.

Never disable security software or delete system files as a first-line fix.
