# Knowledge Base: Software Troubleshooting

**Article ID:** KB-SW-001  
**Category:** Software  
**Audience:** L1 support practice

## Scenario: Business application will not open

### Initial questions

- What is the application name and version?
- Does an error message appear?
- Is the issue affecting one user or several?
- Did the issue begin after an update or configuration change?

### Safe first-line checks

1. Capture the exact error message without exposing confidential information.
2. Confirm the computer meets the application's basic requirements.
3. Check whether the application is already running or unresponsive.
4. Confirm the user is signed in with the expected account.
5. Check approved service-status information, if available.
6. Restart the application and, if appropriate, the device after saving work.
7. Check for approved updates.
8. Do not download installers from unofficial websites.
9. Record all checks and results in the ticket.

### Escalate when

- The issue affects multiple users or a critical business application.
- Licensing, permissions, server connectivity, or backend access is involved.
- Reinstallation or configuration changes require elevated authorization.
