# Knowledge Base: Printer Troubleshooting

**Article ID:** KB-PRN-001  
**Category:** Printer & Peripheral  
**Audience:** L1 support practice

## Scenario: Printer is not responding

### Initial questions

- Is the printer affected for one user or everyone?
- Is it connected by USB or network?
- Is there an error message on the printer?
- Is paper, toner/ink, or a consumable warning displayed?

### Safe first-line checks

1. Confirm the printer is powered on and shows no physical error.
2. Check paper, tray alignment, and visible paper jams using the manufacturer's safe procedure.
3. Confirm the correct printer is selected on the computer.
4. Check whether the printer is online and connected to the approved network or USB port.
5. Check the print queue for paused or stuck jobs.
6. If authorized, clear or cancel the affected user's stuck job.
7. Print a test page if appropriate and permitted.
8. Record the outcome and any error code.

### Escalate when

- Multiple users cannot print to a shared printer.
- There is a hardware fault or recurring paper jam.
- Driver installation or print-server changes require administrator access.
- The printer displays a service or maintenance error.
